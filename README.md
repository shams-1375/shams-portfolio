# Shams Ahmed - Personal Portfolio

🌐 **Live Portfolio:** https://shams-ahmed-portfolio.vercel.app/

A modern and responsive personal portfolio website showcasing my experience, skills, projects, education, and contact information.

## 🚀 Features

- Responsive design for desktop, tablet, and mobile
- Personal introduction and professional summary
- Experience and internship details
- Skills and technologies
- Featured projects with live demos and GitHub repositories
- Education section
- Certifications and recommendation letters
- Contact form
- Smooth animations and transitions
- Mobile-friendly navigation

## 🛠️ Tech Stack

- React.js
- JavaScript
- Tailwind CSS
- Framer Motion
- React Icons
- Vite
